# Project status

- Desktop: local OpenCV/MediaPipe monitor with timestamp-based eye-closure warning/alarm, configurable thresholds, optional sound, calibration, and per-session reports.
- Web: live GitHub Pages browser demo at https://chintalaabhilash17-svg.github.io/driver-drowsiness/ with local camera processing, configurable alerts, local test reports/exports, and no-send SOS demo.
- Privacy: webcam frames are not saved; reports and contacts stay in browser storage. No contact numbers, credentials, or user reports are included in this repository.
- Tests: 11 Python unit tests and 10 browser-core tests pass; syntax checks and MP4 decode smoke check pass.
- Limitations: no completed five-minute live-camera test was available for this portfolio update; the attached narrated video is a camera-off interface walkthrough with automated-test results, not a live-camera test recording. No automated emergency call/SMS provider is configured, WhatsApp delivery is manual and unverified, and location lookup was not confirmed. No universal accuracy or fairness claim is made.
